Het linkermenu van Antigravity

Antigravity is Googles platform om AI-agents code te laten schrijven, draaien en testen: een agent-app en een IDE (een omgebouwde VS Code). Let op: deze pagina komt uit de officiële documentatie. Antigravity staat niet op de computer die aan deze sessie gekoppeld is, dus ik heb het niet in jouw installatie kunnen nalopen.

Overzicht

Een agent-app en een editor

In versie 2 start je in de agent-app: links projecten, gesprekken en geplande taken, midden de chat met de agent. Met Open IDE rechtsboven spring je naar de editor.

AProjecten: een map per project

Elk project hoort bij een map met code. Het tandwiel naast een project opent de projectinstellingen.

BGesprekken: per project gegroepeerd

Elke opdracht aan een agent is een gesprek onder het project waar hij bij hoort.

CSchedule: taken op een tijdstip

Laat een agent op een vast moment iets doen, zoals een controle of een update.

DSettings: algemeen en per project

Globale instellingen, Customizations (MCP-servers toevoegen), en per project wat de agent zonder toestemming mag.

midden
Wat je vindt
Een invoerveld met modelkeuze (Gemini, en ook Claude-modellen) en een /-menu met opdrachten.

Artifacts-paneel

rechts, via het zijpaneel
Wat je vindt
Wat de agent oplevert om te controleren: takenlijst, implementatieplan, walkthrough, code-diffs, screenshots.
Gebruik het voor
Het plan goedkeuren voor de agent begint, en achteraf zien wat hij deed.

Projectinstellingen

⚙ naast een project
Wat je vindt
Security Preset (wanneer de agent toestemming vraagt voor commando's en bestanden), Agent Behaviour (wanneer je artifacts moet goedkeuren), en toegestane paden, URL's en MCP-tools.
Gebruik het voor
Strak beginnen: laat de agent eerst alles vragen.

IDE

Open IDE, rechtsboven
Wat je vindt
Een editor zoals VS Code, met de agent in een zijpaneel, een terminal en een ingebouwde browser.
Gebruik het voor
Zelf meekijken en bijsturen in de code.

Skills en MCP

Settings → Customizations
Wat je vindt
MCP-servers toevoegen, en skills als mappen met een SKILL.md, globaal of per project in .agents/skills/.
Gebruik het voor
Je De Baak-huisstijl ook hier als skill aanbieden.
