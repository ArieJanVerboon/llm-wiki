AOrganisatie: projecten en verbruik

Bij jou één project: Portfoliotemplate in eu-west-3 (Parijs), op de kleinste rekenkracht (Nano). Rechts het verbruik van het gratis plan: database 27 van 500 MB.

BData: tabellen en SQL

Tabellen bekijken en bewerken als spreadsheet, SQL uitvoeren, en schema's, functies en triggers beheren.

CDiensten: inloggen, bestanden, code

Gebruikers en inlogmethoden, opslag voor bestanden, kleine serverfuncties, en live-updates naar een pagina.

DBeheer: controles en instellingen

Automatische controles op beveiliging en snelheid, logs, koppelingen (zoals GitHub) en instellingen, waaronder je API-sleutels.

Jouw werk

Waar zet je het voor in?

Supabase is de database achter je publicatieportfolio. Cloudflare D1 is het alternatief dat je voor je andere sites gebruikt.

Een database met inloggen en bestanden in éénSupabase
Een kleine database naast een Cloudflare WorkerCloudflare D1
Je schema veilig bewarenIntegrations → GitHub (migraties)
Nagaan of je data open staatAdvisors → Security

Nu doen: RLS aanzetten

De Security Advisor meldt dat Row Level Security uit staat op een tabel in het schema public. Dan kan iedereen met de openbare sleutel van je site die tabel lezen en mogelijk wijzigen. Zet RLS aan en maak een policy voor wie mag lezen en schrijven. Ik heb niets veranderd; Claude Code kan de SQL voor je schrijven.
